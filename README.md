# 机电智能一体化设计系统 - 方案比选页面

基于 **Vue 3 + Arco Design Vue** 还原「机电智能一体化设计系统」中的方案比选功能页面。

## 功能特性

- **顶部导航栏**：Logo、系统名称、模块 Tab（项目管理、协同设计、方案比选、限额校验、碰撞检测）、项目信息、通知、用户头像
- **左侧可折叠菜单**：支持展开/收起，内含「优化方案比选」菜单项
- **标题卡片**：展示功能标题和描述，配有横幅图片
- **查询条件区**：
  - 环境切换（测试环境 / 生产环境）
  - 类目多选（风机盘管、空调机组、新风系统等）
  - 查询和重置按钮
- **商品数据表格**：
  - 列：序号、类目名称、材料型号、SPU型号、供应商名称、销售价
  - 支持价格排序
  - 分页功能（10条/页）
  - 斑马纹表格样式

## 技术栈

- Vue 3 (Composition API)
- Arco Design Vue
- Vite

## 启动

```bash
npm install
npm run dev
```

打开 http://localhost:5173 查看效果。
