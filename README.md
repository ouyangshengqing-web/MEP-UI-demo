# 机电智能一体化设计系统

基于 **Vue 3 + Arco Design + ECharts** 还原「机电智能一体化设计系统」设计稿。

## 功能模块

- 设计概览仪表板：4 个核心指标卡片（设备总数 / 运行中 / 维护中 / 故障）
- 年度项目趋势：堆叠柱状图，支持 月度 / 季度 / 年度 切换
- 设备状态分布：环形图 + 图例
- 项目进度：进度列表 + 状态标签
- 团队成员：在线状态指示
- 实时报警：紧急 / 严重 / 警告 三级报警

## 启动

```bash
npm install
npm run dev
```

打开 http://localhost:5173 查看效果。
